# Unity Window — ProBuilder (Text Mode)

This file indexes the structural hierarchy and active states of the standalone ProBuilder Window when rendered in Text Mode within Unity 2022.3.22f1 and ProBuilder 5.2.4.

---

## 🛠️ ProBuilder Element & Tool List

* 🟠 **New Shape** — Opens the shape creation preview and parameters.
    * **Shape Palette**: Grid of primitive icons.
    * **Shape Properties**:
        * **Shape**: Dropdown menu (Selector).
            * Options: Sprite, Plane, Cone, Sphere, Door, Prism, Cube, Cylinder, Stairs, Torus, Arch, Pipe.
        * **Pivot**: Dropdown menu (Selector).
            * Options: Center, First Corner.
        * **Size**: Input fields (X, Y, Z).
    * **Note**: Click and drag in Scene view to place/scale. SHIFT+click to duplicate last settings.
* 🟠 **New Poly Shape** — Enables drawing custom multi-vertex polygon shapes in the Scene view.
* 🟠 **Smoothing** — Opens the smoothing groups configuration panel.
* 🟠 **Material Editor** — Opens the quick material assignment shortcut panel.
* 🟠 **UV Editor** — Opens the comprehensive texture coordinate mapping window.
* 🟠 **Vertex Colors** — Opens the vertex color painting and preset interface.
* 🔵 **Orientation: Global** — Toggles the tool handle orientation matrix between Global and Local.
* 🟢 *Conform Normals* `[Disabled — Greyed out]`
* 🟢 *Export* `[Disabled — Greyed out]` `[ + ]` — Quick export options indicator.
* 🟢 **Lightmap UVs** `[Always Enabled]` `[ + ]` — Opens lightmap UV generation settings.
* 🟢 *Triangulate* `[Disabled — Greyed out]`
* 🟢 *Center Pivot* `[Disabled — Greyed out]`
* 🟢 *ProBuilderize* `[Disabled — Greyed out]` `[ + ]` — Contextual mesh conversion options indicator.
* 🟢 *Subdivide Object* `[Disabled — Greyed out]`
* 🟢 *Flip Normals* `[Disabled — Greyed out]`
* 🟢 *Mirror Objects* `[Disabled — Greyed out]` `[ + ]` — Axis mirror configurations indicator.
* 🟢 *Merge Objects* `[Disabled — Greyed out]`
* 🟢 *Freeze Transform* `[Disabled — Greyed out]`
* 🟢 *Set Trigger* `[Disabled — Greyed out]`
* 🟢 *Set Collider* `[Disabled when no mesh selected]`
